# Fathom Security Policies

## Introduction

Fathom is committed to security and data privacy. This document outlines our core security policies.

## Vulnerability Reporting

If you believe you have found a security vulnerability in Fathom, please DO NOT report it via public GitHub issues.

Instead, please email security@example.com with a full description of the issue.

## Supported Versions

Currently, only the main branch (v1) is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1      | :white_check_mark: |
| v0.x    | :x:                |

## Security Updates

Security updates will be rolled out as quickly as possible. Critical vulnerabilities will be prioritized and a patch released within 48 hours of verification.

## Data Privacy

We only store data essential to the function of Fathom. We do not sell user data.
